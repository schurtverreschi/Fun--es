# Praticando Python
Arquivo utilizado para organizar as atividades praticas do curso de pratica da Alura
## Objetivo:
Revisar e reforçar os conhecimentos aprendidos de funções
## Atividades:
- calculadora_idade: Utiliza o datetime para comparar a data de nascimento informada com a data atual e calcular a idade da pessoa, considerando se ela já fez ou não aniversário;
- contador_caracteres: Transforma uma string em lista para contar quantos caracteres a palavra informada possuí;
- saudação: Cria uma função que recebe um horário e devolve a saudação correspondente, fazendo a transformação de string para int e tratando ValueError caso não seja informado números;
- conversor_tipos: cria duas funções, a primeira responsável por converter o tipo dos elementos da lista de string pra int e a segunda por validar se a conversão foi realmente realizada em todos os elementos da lista;
- total_vendas: Realiza a verificação do input do usuário para validar se foram digitado somente números e realiza a soma dos valores para devolver o total;
- filtrando_números: Verifica se o input do usuário é válido e devolve somente os números pares informados;
- lista_produtos: Pede para o usuário inserir duas listas separadas, produto e preço, combina as listas e devolve formatado;
- calculadora_lambda: Atividade era suposta para utilizar funções lambda para fazer uma calculadora, mas resolvi a atividade utilizando match case, pois não vi necessidade de utilizar uma função e chamar ela logo abaixo sendo que a função lambda era para resolver numa única linha;
