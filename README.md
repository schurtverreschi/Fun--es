# Praticando Python
Arquivo utilizado para organizar as atividades praticas do curso de pratica da Alura
## Objetivo:
Revisar e reforçar os conhecimentos aprendidos de funções
## Atividades:
- calculadora_idade: Utiliza o datetime para comparar a data de nascimento informada com a data atual e calcular a idade da pessoa, considerando se ela já fez ou não aniversário;
- contador_caracteres: Transforma uma string em lista para contar quantos caracteres a palavra informada possuí;
- saudação: Cria uma função que recebe um horário e devolve a saudação correspondente, fazendo a transformação de string para int e tratando ValueError caso não seja informado números;
